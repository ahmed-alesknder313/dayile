# حياتي المالية

تطبيق ويب لإدارة المال والحياة اليومية، يعمل على الهاتف والحاسوب ويمكن تثبيته كتطبيق (PWA). لا يحتاج أي تثبيت أو سيرفر: ملفات ثابتة فقط.

## الملفات
- `index.html`: التطبيق كاملاً (الصفحة والتصميم والمنطق)
- `manifest.webmanifest` و`icon-192.png` و`icon-512.png` و`icon.svg`: التثبيت كتطبيق والأيقونات
- `sw.js`: يخزّن الصفحة ليعمل التطبيق بدون إنترنت بعد أول فتح
- `404.html` و`.nojekyll`: لـ GitHub Pages
- `netlify.toml` و`vercel.json`: إعدادات اختيارية لـ Netlify وVercel

## النشر
**GitHub Pages:** ارفع كل الملفات إلى مستودع، ثم Settings ← Pages ← Branch: main ← Folder: root ← Save. الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

**Netlify:** اسحب المجلد كاملاً إلى app.netlify.com/drop.

**Vercel / Cloudflare Pages:** اربط المستودع واترك أمر البناء فارغاً ومجلد الإخراج `/`.

التثبيت كتطبيق يحتاج رابط https (توفره هذه المنصات تلقائياً).

## ملاحظات
- البيانات الحالية تجريبية وتُحفظ العملة فقط في متصفح المستخدم. لمنتج تجاري تُضاف حسابات مستخدمين وقاعدة بيانات (مثل Supabase).
- الخط يُحمَّل من Google Fonts، وإن لم يتوفر يُستخدم خط النظام.
